# LifePlanner — Asset & Audio Spec

Reference for the Phase 2 art and audio drops. Everything below is verified against the code on `main`; the file paths and key names are what the runtime loaders look for. As long as a file lands in the right slot, it just works — no code changes required per asset.

## Conventions

- **Image assets** live in `LifePlanner/Resources/Assets.xcassets/<name>.imageset/`. Loader: `UIImage(named:)` → `SKTexture(image:)`, called from [LifePlanner/UI/Farm/PlotTextureFactory.swift](../LifePlanner/UI/Farm/PlotTextureFactory.swift). PNG with alpha, sRGB color space.
- **Audio assets** live in the LifePlanner app target's resources (e.g. `LifePlanner/Resources/Sounds/<name>.<ext>`). Loader tries extensions in order: **`.caf` → `.mp3` → `.wav` → `.m4a`**. First match wins. Code lives at [LifePlanner/Utilities/SoundPlayer.swift](../LifePlanner/Utilities/SoundPlayer.swift).
- **Partial delivery is fine.** Every missing image falls back to a procedural placeholder; every missing audio file silently no-ops. Drop one in, ship it — the rest stay on placeholders until they arrive.

## Image assets — 26 imagesets

### Recommended source size

`PlotNode.tileSize = 80` pt, so the @3x rasterization is 240×240 px. Two equally valid authoring paths:

- **Single source PNG, 240×240, `single-scale: true` in the imageset's `Contents.json`.** Xcode/SpriteKit downsample for @2x and @1x displays. Simplest.
- **Three explicit variants:** `*@1x.png` 80×80, `*@2x.png` 160×160, `*@3x.png` 240×240. Pixel-perfect at every density but 3× the files to manage.

`hud_gold_icon` is smaller (24 pt) — 72×72 source single-scale is plenty.

### Authoring guidance

- **Pick one style** (top-down, 3/4 top-down, or pixel art) and apply consistently across all 25 plot tiles. Visual coherence across the farm matters more than per-tile detail.
- **State progression must read at a glance.** Empty → Growing → Mature should clearly intensify (color saturation, sprite size, fruiting). Withered should look obviously desaturated. Dead should read as terminated, not just sad.
- **Transparent backgrounds** (or transparent rounded corners) so tiles composite over SpriteKit's ground layer cleanly.
- **Keep negative space** around the sprite — leave ~10% margin inside the 240×240 frame so health-bar overlays and any animation jitter don't clip.

## Audio assets — 4 files

`SoundPlayer` uses `AVAudioSession.category = .ambient` — audio mixes with the user's music and respects the silent switch. Design for "nice texture," not "the user is paying attention."

| Filename (base) | Fires when | Recommended format | Duration | Specs | Volume |
|---|---|---|---|---|---|
| `sfx_contribution` | Habit logged or task checked off | **`.caf`** or `.wav` | 100–250 ms | 16-bit PCM, 44.1 kHz, mono | 0.4 (default) |
| `sfx_quest_claim` | Quest auto-claims (task / habit / harvest / weekly) | **`.caf`** or `.wav` | 250–600 ms | 16-bit PCM, 44.1 kHz, stereo OK | 0.4 |
| `sfx_quest_reroll` | User taps re-roll in the quest log | **`.caf`** or `.wav` | 150–400 ms | 16-bit PCM, 44.1 kHz, mono | 0.4 |
| `sfx_farm_ambience` | Loops while the Farm tab is visible | **`.mp3`** or `.m4a` | 30–60 s, seamlessly loopable | 128 kbps AAC/MP3, stereo, 44.1 kHz | 0.15 |

### Wiring (already in place)

| Effect | Call site |
|---|---|

| `sfx_quest_claim` | [QuestInteractor.credit](../LifePlanner/Interactors/QuestInteractor.swift) — already wired via `SoundPlayer.shared.play(.questClaim)`. |

| `sfx_farm_ambience` | Started / stopped from the Farm tab's appearance lifecycle (currently wired through `AmbientLifeController`). |

### Authoring guidance

- **`sfx_contribution`** plays often and at low volume. Quality > file size. Crisp positive "ding" — sparkle, water droplet, or seed-plant flavor. Avoid anything ear-fatiguing on repeat.
- **`sfx_quest_claim`** is a reward chime — coin cha-ching, victory ping. Slightly more emphatic than contribution; this is the "you did it" moment.
- **`sfx_quest_reroll`** is a spending sound — dice tumble, shuffle. Should feel meaningfully distinct from `sfx_quest_claim` (one costs gold, the other awards it).
- **`sfx_farm_ambience`** must loop seamlessly. Author the source with zero-crossings at the start and end, or fade in/out into silence at the join point. Bird chirps, distant cowbell, gentle wind — pastoral background bed.
